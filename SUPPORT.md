# Support

Use the repository issue forms for reproducible defects, feature proposals, and usage questions. Check the [documentation index](docs/README.md) before opening an issue.

The dedicated repository and its issue tracker are pending publication; see [Development status](README.md#development-status-and-declared-compatibility). Until then, contact the Kanban CCEAD maintainer through an established channel. Do not direct fork-specific support requests to the upstream maintainer.

Support requests should include the Moodle version, plugin release, PHP version, database engine, and the relevant activity configuration. Do not include passwords, session keys, student data, or production logs containing personal information.

This repository does not provide guaranteed response times, private implementation support, or support for unsupported Moodle versions.

For a security vulnerability, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
